The core of the platform

PLC «Operator 27» — the controller that never loses the cycle

A central processor module of our own design, running our own real-time operating system. Serially produced and in stock. This is the brain installed in every OPERATOR barn.

200 ms recovery

After a power outage the cycle resumes from the saved position — FRAM memory with no write-cycle limit. No reboot, no manual restart, no scraper stuck mid-alley. Imported systems reboot and wait for an operator.

600+ self-diagnosed events

Every output and input circuit is monitored for breaks, shorts and overheating. Faults surface before they stop the barn.

Open by design

Full REST API (OpenAPI), Modbus TCP/RTU, WebSocket and MQTT. Built-in web interface for setup, monitoring and remote access.

Barn-proof hardware

Operating range −40…+60 °C, galvanically isolated I/O (1500 V), modular expansion up to 32 boards.
